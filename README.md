# 🎬 CineLog

Aplicativo mobile desenvolvido em **React Native com Expo** para explorar e organizar conteúdos de entretenimento, como **filmes, séries e animes**, oferecendo uma interface simples, moderna e intuitiva.

---

## 📱 Sobre o projeto

O **CineLog** foi desenvolvido com o objetivo de criar uma experiência mobile para usuários que gostam de acompanhar e descobrir diferentes tipos de conteúdos.

A aplicação conta com uma interface organizada por categorias e componentes reutilizáveis, permitindo uma navegação simples pelo catálogo.

O projeto também foi desenvolvido como forma de aplicar na prática conceitos de desenvolvimento mobile utilizando **React Native**, **Expo** e **JavaScript**.

---

## ✨ Funcionalidades

* 🎬 Catálogo de filmes
* 📺 Catálogo de séries
* 🍿 Catálogo de animes
* 🔎 Organização dos conteúdos por categorias

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Matheus-cyber0928/CineLog.git
```

### 2. Acesse a pasta do projeto

```bash
cd CineLog
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o projeto

```bash
npx expo start
```

Após iniciar o Expo, será possível executar a aplicação utilizando:

* 📱 **Expo Go** em um dispositivo físico
* 🤖 **Android Emulator**
* 🍎 **iOS Simulator**
* 🌐 **Web Browser**
